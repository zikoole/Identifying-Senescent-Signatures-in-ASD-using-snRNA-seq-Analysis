# Identifying-Senescent-Signatures-in-ASD-using-snRNA-seq-Analysis

## Overview
This project use Scanpy to analyze snRNA-seq data from ASD and control cortex to identify cell-type-specific senescent-like states. SenMayo gene set is used to compute SASP scores across 17 brain cell types, finding neuronal upregulation and endothelial/oligodendroglial decreases, suggesting neuronal senescence as a contributor to ASD pathology and a potential therapeutic target.

## Dataset
1. ASD snRNA-seq dataset, Speir et al. (https://doi.org/10.15585/mmwr.ss7402a1)
2. Human Gencode V49 for gene mapping (Ensembl ID -> gene symbol), Mudge et al. (https://doi.org/10.1093/nar/gkae1078)
3. SASP gene set: SenMayo by Saul et al. (https://doi.org/10.1038/s41467-022-32552-1)
   
## Workflow
1. align expression matrix with meta
2. pre-processing: QC, HVG & PCA, cell clustering
3. use SenMayo gene set to calculate SASP score; visualize using UMAP and violin plot
4. run Mann-Whitney U test, FDR correction, and calculate Cohen's d value; visualize using volcano plot

## Results
UMAP & Violin showing SASP scores (results/figures/umap_sasp.png; results/figures/violin_plots)
Volcano showing p value and Cohen's d value (results/figures/volcano_plots)
