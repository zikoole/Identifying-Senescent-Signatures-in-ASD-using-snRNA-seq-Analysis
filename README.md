# Identifying-Senescent-Signatures-in-ASD-using-snRNA-seq-Analysis
This project analyzes snRNA-seq data from ASD and control cortex to identify cell-type-specific senescent-like states. SenMayo gene set is used to compute SASP scores across 17 brain cell types, finding neuronal upregulation and endothelial/oligodendroglial decreases, suggesting neuronal senescence in ASD pathology.
